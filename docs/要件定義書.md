# 寮くじ清算ツール 要件定義書

## 1. 目的

寮イベントのくじ（4桁番号）を一括で入力し、各番号の当選等級・景品を判定して、必要な景品の個数を集計する。

## 2. 利用方法

- `index.html` をブラウザで開く（サーバー・インストール不要）。
- くじ番号を続けて入力し、「清算する」を押す。
- 入力欄は数字4桁ごとに自動で区切る（5桁目は次の番号の1桁目として扱う）。数字以外の文字は無視し、全角数字は半角として扱う。
- 「RESET」ボタンで入力欄と結果をすべて消去する。

## 4. 当選判定ルール

1. 入力された4桁番号が1等の番号と完全一致する場合、1等を適用する。
2. 1等に該当しない場合、2等の番号と完全一致するか確認する。
3. 1等・2等に該当しない場合、下2桁が3等の当選番号と一致するか確認する。
4. 1〜3等の判定とは別に、下1桁によって4等を判定する。
5. 1〜3等のいずれかに該当し、かつ4等にも該当する場合は、**両方の景品を贈呈する**（重複当選）。
6. どの等級にも該当しない番号は当選なしとして扱う。ただし今回の4等は下1桁の全数字を網羅しているため、通常は当選なしにならない。

※ 1〜3等は上位優先で、いずれか1つのみ適用する（1等と2等、2等と3等などの同時当選はない）。

## 5. 一括清算の集計ルール

- 入力した番号ごとに、当選等級と景品名を表示する（重複当選の場合は全ての等級・景品を表示）。
- 4等の景品は「下1桁（景品名）」の形で表示する（例：`3（じゃがりこ）`、`2（堅あげポテト）`）。景品別集計では4等を下1桁の番号順に並べる。
- 同じ景品が複数回当選した場合は、景品ごとに個数を合算する。
- 等級別の当選件数を集計する。
- 景品別集計では、景品名・等級・必要個数を表示する。
- 4桁番号は文字列として扱う（`0122` の先頭0を保持する）。
- 最後に4桁に満たない端数が残った場合はエラーとして表示し、清算対象から除外する。
- 同じ番号が複数回入力された場合も除外せず、入力された回数分それぞれ清算・集計する。
